# Guía de C — Biblioteca estándar (C99)

Referencia interactiva de las 24 cabeceras de la biblioteca estándar de C, en español.

Uso en cualquier web:

```html
<script src="https://cdn.jsdelivr.net/gh/josesamuelquintero/guia-c@v1.0.0/guia-c.js"></script>
```

`guia_c.json` contiene los mismos datos.
